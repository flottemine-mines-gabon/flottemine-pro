Configuration requise

Avant d'utiliser l'application, connectez-la à votre projet Supabase.

Les clés Supabase n'ont pas encore été renseignées dans le fichier index.html.
  1. Ouvrez votre projet sur supabase.com
  2. Allez dans Project Settings → API
  3. Copiez Project URL et la clé anon / public
  4. Dans index.html, remplacez SUPABASE_URL et SUPABASE_ANON_KEY tout en haut du script
  5. Re-uploadez le fichier sur GitHub
